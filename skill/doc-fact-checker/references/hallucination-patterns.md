# AI 할루시네이션 패턴 카탈로그

1단계 주장 인벤토리 작성 시 이 목록과 대조한다. 패턴에 해당한다고 곧바로 오류인 것은 아니다 — 검증 우선순위를 높이는 신호로 쓴다.

## 패턴 1. 통계 환각 — 정밀해 보이는 가짜 수치

**특징**: 소수점까지 붙은 그럴듯한 수치를 출처와 함께(또는 출처 없이) 제시한다. "국내 중소기업의 68.3%가 AI 도입을 검토 중이다" 같은 문장. 실재하는 조사의 다른 연도 수치를 가져오거나, 존재하지 않는 조사를 만들어내는 두 형태가 있다.

**탐지 신호**
- 소수점 한 자리까지 정확한 비율인데 조사명·표본·시점이 없음
- 출처가 기관명뿐이고 보고서명·발표일이 없음 ("통계청에 따르면")
- 주장에 지나치게 유리한 수치 (딱 맞아떨어지는 근거)

**검증**: 기관명 + 핵심 수치 + 연도로 검색. 해당 기관의 공식 발표에서 같은 수치가 확인되면 ✅, 비슷한 조사는 있으나 수치가 다르면 ❌(실제 수치 병기), 조사 자체를 찾을 수 없으면 ⚠️ 의심.

## 패턴 2. 출처 환각 — 존재하지 않거나 내용이 다른 인용

**특징**: 세 가지 변형이 있다. (a) 완전히 지어낸 보고서·논문·기사, (b) 실존 기관 + 가짜 보고서 제목의 조합, (c) 가장 위험한 변형 — 실재하는 출처를 인용하되 내용을 왜곡. URL이 그럴듯한 형식이지만 404인 경우도 여기 속한다.

**탐지 신호**
- 제목이 지나치게 문서 주제와 정확히 일치하는 보고서
- 저자·발행 연도·페이지 등 서지 정보가 일부만 있음
- URL 경로가 일반적인 패턴 조합처럼 보임 (`/report/2025/ai-adoption-survey.pdf`)

**검증**: 출처 실재 여부와 내용 일치 여부를 반드시 분리해서 본다. URL은 web_fetch로 직접 연다. 보고서·기사는 제목으로 검색해 원문을 찾고, 문서가 인용한 대목과 원문의 해당 대목을 나란히 대조한다. 실재하지만 내용이 다르면 원문의 실제 문구를 근거로 첨부한다.

## 패턴 3. 법령 환각 — 가장 빈번하고 가장 위험

**특징**: 법령 인용은 AI 할루시네이션 최다 발생 영역이다. 변형: (a) 실재하는 법의 존재하지 않는 조문 번호, (b) 조문은 실재하나 내용이 다름, (c) 폐지·전부개정된 법령을 현행처럼 인용, (d) 법률·시행령·시행규칙의 위계 혼동, (e) 이름이 비슷한 다른 법과의 혼동.

**탐지 신호**
- 조문 번호와 내용 요약이 함께 제시됨 (요약이 틀렸을 확률이 높음)
- "○○법 제XX조에 따라 ~해야 한다" 형태의 의무 규정 인용
- 법령명이 축약형으로만 표기됨 (정식 명칭 확인 필요)

**검증**: 국가법령정보센터(law.go.kr)를 기준으로 삼는다. 법령 정식 명칭 → 조문 번호 실재 → 조문 원문과 문서의 요약 대조 → 현행 여부(시행일·개정 이력) 순으로 확인한다. 블로그·뉴스의 법령 해설은 근거로 쓰지 않는다.

## 패턴 4. 기관·사업 환각 — 존재하지 않는 제도

**특징**: 존재하지 않는 정부 지원사업명, 폐지된 사업의 현행 인용, 잘못된 주관기관, 존재하지 않는 인증·자격 제도, 인물의 잘못된 직책.

**탐지 신호**
- 사업명이 정책 키워드의 조합처럼 보임 ("중소기업 AI 전환 바우처 지원사업")
- 예산 규모·모집 인원이 구체적인데 공고 연도가 없음
- 주관기관과 전문기관(수행기관)이 뒤섞여 표기됨

**검증**: 사업명으로 검색해 공고 원문(기관 공식 사이트, 기업마당, K-스타트업 등)을 찾는다. 사업명·주관기관·예산·시기가 모두 일치해야 ✅. 유사한 이름의 다른 사업이 나오면 혼동 가능성을 명시하고 ⚠️.

## 패턴 5. 계산 환각 — 형식은 맞고 답이 틀린 산수

**특징**: 계산 과정을 그럴듯하게 서술하면서 결과값이 틀린다. 표의 합계 불일치, 성장률·CAGR 오류, 억/만 단위 환산 착오, % 와 %p 혼동, 세전·세후 혼동이 대표적이다. AI는 자릿수가 큰 곱셈과 거듭제곱에서 특히 자주 틀린다.

**탐지 신호**
- "A × B = C" 형태로 계산식과 결과가 함께 제시됨 (반드시 재계산)
- 합계·소계가 있는 모든 표
- 연평균 성장률, 배수, 비중 등 파생 수치

**검증**: 예외 없이 Python으로 재계산한다. 이 패턴은 탐지 신호와 무관하게 문서의 모든 계산에 적용한다.

## 패턴 6. 시제 환각 — 시점의 뒤엉킴

**특징**: 미래 예정 사항을 완료된 것처럼 서술, 오래된 데이터를 최신처럼 인용, "2026년 현재"라는 표현과 실제 데이터 연도의 불일치, 예측치와 실적치의 혼용.

**탐지 신호**
- "현재", "최근", "지난해" 같은 상대적 시점 표현 + 구체 수치
- 발표 예정이었던 정책·제품을 기정사실로 서술
- 전망치(E, F 표기)가 실적처럼 인용됨

**검증**: 문서의 기준 시점을 먼저 고정한 뒤, 각 수치의 실제 기준 연도를 출처에서 확인해 대조한다. 기준 시점에는 맞았으나 이후 갱신된 수치는 오류가 아니라 "업데이트 권장"으로 분류한다.

## 패턴 7. 권위 차용 환각 — 익명의 전문가들

**특징**: "전문가들은 ~라고 본다", "연구에 따르면", "업계에서는 ~로 알려져 있다"처럼 특정할 수 없는 권위를 빌려 주장을 강화한다. 참/거짓 판정이 불가능하도록 설계된 문장이다.

**탐지 신호**: 주어가 익명 집단이고 서술어가 단정형인 문장.

**검증**: 판정 대상이 아니라 문서 품질 문제로 다룬다. 해당 주장을 뒷받침하는 실제 출처를 찾아 제안하거나, 찾지 못하면 삭제 또는 "~로 판단된다"류의 의견 표현으로 완화하기를 수정안으로 제시한다.

## 패턴 8. 정합성 붕괴 — 이어붙인 흔적

**특징**: AI가 섹션별로 따로 생성한 문서에서 자주 나타난다. 요약의 수치와 본문의 수치가 다름, 앞에서 정의한 용어가 뒤에서 다른 의미로 쓰임, 표와 본문 서술의 불일치, 결론이 본문에 없는 근거를 전제함.

**탐지 신호**
- 같은 대상을 가리키는 수치가 문서에 2회 이상 등장 (파서의 동일 값 그룹 활용)
- 목차·요약·본문 3곳에 반복되는 핵심 주장
- 섹션 간 문체·표기 방식의 급격한 변화 (생성 단위가 다르다는 신호)

**검증**: 외부 검색 없이 문서 내 대조만으로 확정 판정이 가능하다. 반복 등장하는 모든 핵심 수치·용어·주장을 표로 만들어 상호 대조한다.

## 문장 수준 위험 신호 종합

아래 신호가 겹칠수록 검증 우선순위를 높인다.

- 출처 없는 소수점 통계
- 모든 수치가 5·10 단위로 딱 떨어지는 "너무 깨끗한" 데이터
- 순위 주장 ("국내 1위", "세계 3대")에 근거 없음
- 인용 표기는 있으나 접근 경로(URL, 보고서명, 발행일)가 없음
- 최상급 표현 + 구체 수치의 조합 ("가장 빠른 성장률인 34.7%")
- 법령·규정 인용에 조문 원문 발췌가 없음
- 문서 주제에 지나치게 유리한 방향으로만 정렬된 근거들
